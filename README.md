# Danger Wear — public preview

Publiczny podgląd roboczej wersji strony **Danger Wear Production**.

**Preview:** https://sydesignest2013.github.io/danger-wear-preview/

Aktualny build zawiera kompletną nawigację, 27 kart produktowych, responsywny layout desktop / tablet / mobile, hero `DANGER WEAR / PRODUCTION / Quality. End of story` oraz akcent `#8A0303`.

Przy pierwszym wdrożeniu workflow pobiera przygotowaną paczkę mediów z projektowego Google Drive, dodaje obrazy do repozytorium i od tej chwili GitHub zawiera również media lokalnie. Kolejne wdrożenia korzystają już z plików zapisanych w repo.

Repozytorium służy jako publiczny preview wersji roboczej, nie jako final produkcyjny.
